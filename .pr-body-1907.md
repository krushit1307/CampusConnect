## Description

Adds comprehensive Playwright E2E tests for the club creation/onboarding flow via the `CreateClubDialog` component on the `/clubs` page.

### Changes

- **`e2e/club-onboarding.spec.ts`** — new Playwright test file with 7 tests:

  1. **Dialog opens** — verifies "Create a Club" button and dialog heading are visible
  2. **Slug auto-generation** — types a club name and verifies the slug auto-populates in kebab-case
  3. **Manual slug override** — verifies editing the slug manually keeps the custom value
  4. **Validation errors** — submits empty form and verifies dialog stays open (form not submitted)
  5. **Description character count** — fills description and verifies the length counter
  6. **Escape key close** — opens dialog, presses Escape, verifies it closes
  7. **Authenticated creation** — mocks Supabase auth session in localStorage, intercepts the Supabase `POST /clubs` REST call, submits form, verifies success toast appears
