## Description

Adds preference-gated Web Audio UI micro-interactions without shipping audio assets. The existing oscillator-based `AudioEngine` now respects `localStorage.sound_enabled`, exposes toggle/like sound profiles, and stays silent by default until users enable sounds in Settings.
