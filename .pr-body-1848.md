## Description

Completes the High Contrast Mode toggle, making it a first-class theme option alongside Light, Dark, and System.

### Changes

- **`theme-provider.tsx`**
  - Added `"high-contrast"` to the `Theme` type
  - Updated `getStoredTheme()` to persist and restore high-contrast preference
  - Updated `getPreferredTheme()` to detect OS-level `prefers-contrast: more`
  - Updated `applyTheme()` to toggle `.high-contrast` class on `<html>` (high-contrast disables `.dark` class since it uses its own pure-B&W variables)
  - Added `prefers-contrast: more` media query listener in system mode so HC auto-follows OS changes
  - Updated `toggleTheme()` to cycle through all 4 themes (light → dark → high-contrast → system → light)

- **`styles.css`**
  - Added `@custom-variant high-contrast` so `high-contrast:` Tailwind classes work project-wide
  - Added `.high-contrast` CSS variables block with pure black-on-white / white-on-black values
  - Added `.high-contrast body` override (solid white background, no decorative gradient)
  - Added `.high-contrast a` overrides (always underlined, yellow hover bg for max contrast)

- **`settings.tsx`**
  - Added missing `useTheme` import
  - Added **High Contrast** button in Appearance panel theme selector
  - Removed dead local `ThemeToggle` helper component (was broken code, unused)

- **`disabled-buttons.css`** — already had `.high-contrast` disabled button styles (unchanged)
- **`ThemeToggle.tsx`** — already had `"high-contrast"` cycling logic and `high-contrast:` classes (unchanged)
- **`globalState.ts`** — already had `"high-contrast"` in its union type (unchanged)
