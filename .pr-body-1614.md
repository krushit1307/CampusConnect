## Description

Pauses off-screen heavy animations to improve performance and reduce battery drain when components are not visible in the viewport.

### Changes

- **`src/hooks/useOnScreen.ts`** — new reusable hook using `IntersectionObserver` that returns `[ref, isVisible]`. Handles cleanup on unmount.
- **`src/components/media/AudioReactiveBackground.tsx`** — applies `useOnScreen` to cancel the 60FPS `requestAnimationFrame` WebGL render loop when the component scrolls out of view. Resumes automatically when scrolled back in.

The heaviest animation consumer (WebGL shader rendering at 60FPS) is now paused when not visible. The hook is generic and can be applied to other animation-heavy components as needed.
